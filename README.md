Virtual Stock Trading App (StockSim V.1)
Project Overview
An educational stock-trading simulator built for college academic demonstration. It allows users to manage virtual funds, trade simulated stocks, track portfolios, and monitor profit/loss without real financial risk.

Problem Statement
Students and beginners often want to understand stock market dynamics, portfolio compounding, and trading mechanics without risking real capital.

Objectives
Provide a risk-free virtual trading environment.
Simulate realistic stock price fluctuations.
Maintain independent multi-user portfolios and transaction logs.
Include a robust administrative control module.
Features
User Authentication: Secure signup with validation, unique ID generation, and ₹1,00,000 initial virtual cash.
Market Simulator: 10 pre-configured stocks with automated price variations.
Trading Operations: Buy and Sell modals with real-time balance checks and average buy price calculation.
Portfolio Management: Real-time investment tracking, current valuation, and P&L computation.
Admin Portal: User management, balance reset, stock CRUD operations, and system-wide transaction monitoring.
Technologies Used
HTML5
CSS3 (Flexbox & Grid, CSS Variables)
Vanilla JavaScript (ES6+)
Browser Local Storage
How to Run
Open the project folder in VS Code.
Install the Live Server extension by Ritwick Dey.
Right-click index.html and select Open with Live Server.
